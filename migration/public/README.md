# Public migration manifests

This directory will contain only sanitized, versioned route and asset contracts. Do not place WXR exports, excluded-record details, fingerprints, acquisition logs, or private media evidence here.

The initial privacy harness treats `migration/private/`, `migration/fingerprints/`, `migration/audit/`, `migration/staging/`, `migration/cache/`, and `migration/logs/` as prohibited public paths.
